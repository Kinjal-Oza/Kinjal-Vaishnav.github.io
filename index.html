Why One Agent Is Never Enough: A Multi-Agent Architecture for Infrastructure Observability

SSRN · DOI 10.2139/ssrn.7125618 · Posted July 2026

A four-agent architecture — Supervisor, Telemetry Investigation, Reasoning, and Action — coordinated through typed shared state for infrastructure incident investigation. Includes a documented set of multi-agent failure modes and a public LangGraph reference implementation.

Predictive GPU Failure Detection via Continuous Health Scoring: A Reproducible Study on Synthetic Fleet Telemetry

Zenodo · DOI 10.5281/zenodo.21500285 · CC-BY 4.0 · Published July 2026

Treats each GPU as a stateful entity with a continuous health score estimating near-term failure risk from telemetry trends. On a held-out synthetic set of 500 GPUs, the health score warns a median of 24 hours before failure at a 90% precision operating point, versus 2 hours for a static-threshold baseline.
